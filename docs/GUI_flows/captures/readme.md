# GUI 캡처 및 검증 기록

이 폴더에는 GUI의 등록·비교·결과 저장 흐름을 확인하면서 생성한 원본 화면과 실행 결과를 보관합니다. 화면 예시는 [전체 흐름 이미지](../00_overview.png)에서 볼 수 있습니다. 학습이나 일반 GUI 실행에 필요한 폴더는 아닙니다. 이 README만 저장소에 포함하며, 아래 원본 캡처·실행 결과·샘플 이미지·요약 JSON은 로컬 자료로 Git에서 제외합니다. 새 Clone에는 상위 폴더의 화면 모음 PNG만 포함됩니다.

| 항목 | 내용 |
|---|---|
| `frames/` | 실제 Qt 위젯을 렌더링한 단계별 화면 캡처. 상위 폴더의 화면 모음 PNG를 만드는 원본입니다. |
| `results/` | 단일 모델·여러 모델·외부 폴더 입력 시나리오의 비교 결과, CSV·HTML·SVG 리포트와 `.fpt` Template. |
| `external_demo/` | 외부 폴더 입력을 확인하기 위해 FVC2002에서 복사한 샘플 이미지. |
| `capture_summary.json` | 캡처 시각, 사용 모델, 임계값, 판정 결과, 코드·Weight 해시와 해당 실행 경로. |

## 기록 해석

- `results/`의 `run_1`, `run_2` 등은 반복 실행마다 생성한 저장 폴더입니다. 서로 다른 Seed의 학습 실험을 의미하지 않습니다. 요약 파일은 캡처에 사용한 실행을 가리킵니다.
- 캡처 당시에는 `models/current`의 모델을 사용했습니다. 해당 Weight는 이후 정리했으며 실행 기록은 `models/validation/runs/cosine30_seed42_20epoch`에 보존합니다. 이 캡처 폴더에는 학습 Weight가 없습니다.
- 실제 GUI를 Qt offscreen 방식으로 렌더링했습니다. 데스크톱에서의 수동 조작 검증을 의미하지 않습니다.
- 외부 폴더 시나리오도 기존 DB 이미지의 복사본을 사용했습니다. 기능 확인용이며, 미학습 손가락이나 새로운 센서의 정확도를 검증한 결과는 아닙니다.
- 실행 당시 결과를 보존하므로 HTML·설정 파일에 기록된 절대 경로는 현재 저장 위치와 다를 수 있습니다. 폴더명을 바꿔도 원본 점수·Template·실행 기록은 수정하지 않습니다.

## 캡처 갱신

GUI에서 등록·비교·결과 저장을 실제로 수행한 뒤 단계별 화면을 새로 저장합니다. 원본 화면은 900×720 크기로 유지하고, 상위 폴더의 화면 모음 PNG와 같은 배치로 정리합니다. 캡처·화면 합성용 보조 도구는 정리했으며 기존 원본과 결과는 보존합니다.

실행 당시의 모델·임계값·판정은 `capture_summary.json`과 해당 결과 폴더를 기준으로 확인합니다. 코드나 모델이 바뀌었다면 새 실행 결과를 별도로 저장하고, 이전 기록을 현재 버전의 결과처럼 사용하지 않습니다.
